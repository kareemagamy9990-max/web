لوحة تحكم الموقع

سجّل الدخول بـ GitHub token عشان تعدّل محتوى الموقع. التعديلات بتتحفظ على الريبو، والموقع بيتحدث لوحده خلال دقيقة.

إعدادات الريبو

إزاي أعمل Token؟
  1. ادخل GitHub بالحساب صاحب الريبو، وافتح Fine-grained tokens ← Generate new token.
  2. في Resource owner اختار الحساب صاحب الريبو (مش حسابك الشخصي لو مختلف).
  3. في Repository access اختار Only select repositories واختار ريبو الموقع.
  4. في Permissions ← Repository permissions خلّي Contents = Read and write.
  5. اضغط Generate، وانسخ الـ token وحطه هنا.
